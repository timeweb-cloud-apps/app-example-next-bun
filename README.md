# next on bun

Пример next на bun для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `bun` |
| Фреймворк в API | `next.js` |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `out` |

## Локальный запуск

```bash
bun install
bun run build
```
